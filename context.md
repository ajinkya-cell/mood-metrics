# crypto-mood — Project Context

## What is this?

A **Next.js** web application that aggregates cryptocurrency market sentiment from multiple sources (Reddit, CoinGecko, crypto news RSS), analyzes posts with **AI (Nvidia NIM — Llama 3.1 8B)**, and produces a blended sentiment score for major cryptocurrencies (BTC, ETH, SOL).

---

## Architecture (Four-Layer Sentiment)

```
  ┌── Flash (45%) ──┐ ┌─ Historic (35%) ┐ ┌─ Funding (15%) ─┐ ┌─ F&G (5%) ─┐
  │ CoinGecko + RSS  │ │    Reddit AI    │ │ Binance Futures │ │ alternative  │
  └────────┬─────────┘ └────────┬────────┘ └────────┬────────┘ └──────┬──────┘
           └────────────────────┼────────────────────┼────────────────┘
                                ▼
                       ┌────────────────┐
                       │ /api/analyze   │
                       │   45/35/15/5   │
                       └────────────────┘
```

1. **Flash Layer** (45% weight) — Combines CoinGecko news updates and crypto news RSS feeds. Refreshed dynamically on user request or every 30 minutes.
2. **Historical Layer** (35% weight) — Reddit subreddit post scraping and AI sentiment analysis. Pre-aggregated into hourly buckets. Refreshed via cron every 6 hours.
3. **Funding Rates Layer** (15% weight) — Binance perpetual funding rates scraper. Reflects leveraged market positioning. Normalized on a `-1.0` (highly bearish leverage) to `+1.0` (highly bullish leverage) scale, capped at `±0.10%`. Refreshed every 30 minutes.
4. **Fear & Greed Layer** (5% weight) — Global crypto Fear & Greed Index from alternative.me. Normalized from its `0..100` range to a `-1.0` to `+1.0` scale. Refreshed every 30 minutes.

The [app/api/analyze/route.ts](file:///C:/Users/ajink/OneDrive/Desktop/personal%20-%20coding%20-%20ventures/crypto-mood/app/api/analyze/route.ts) endpoint pulls and combines these four components dynamically to output the final blended score.

## Database Schema (6 tables + 3 enums)

### Enums
- `sentiment_label` — `bullish` | `bearish` | `neutral`
- `source_type` — `reddit` | `coingecko` | `news_rss`
- `interval_type` — `1h` | `4h` | `1d`

### Tables
1. **`tickers`** — Cryptocurrencies tracked by the system
   - `id` (uuid, primary key, default random)
   - `symbol` (varchar(20), unique, not null) — e.g. `BTC`
   - `name` (varchar(100), unique, not null) — e.g. `Bitcoin`
   - `coingeckoId` (varchar(100)) — API identifier for CoinGecko
   - `redditName` (varchar(100)) — Target subreddit name (e.g. `bitcoin`)
   - `isActive` (boolean, default true, not null)
   - `createdAt` (timestamp, default now, not null)

2. **`raw_posts`** — Scraped raw posts/articles from all ingestion layers
   - `id` (uuid, primary key, default random)
   - `tickerId` (uuid, foreign key referencing `tickers.id`, cascade delete, not null)
   - `sourceType` (source_type enum, not null)
   - `externalId` (varchar(500)) — Unique identifier from source (e.g. post ID or URL) to prevent duplicates
   - `title` (varchar(500))
   - `content` (text, not null)
   - `author` (varchar(200))
   - `url` (varchar(1000))
   - `upvotes` (integer, default 0)
   - `commentCount` (integer, default 0)
   - `postedAt` (timestamp, not null)
   - `scrapedAt` (timestamp, default now, not null)
   - *Indexes*: `raw_posts_ticker_idx` (`tickerId`), `raw_posts_posted_at_idx` (`postedAt`), `raw_posts_source_idx` (`sourceType`), unique index `raw_posts_external_id_ticker_unique` (`externalId`, `sourceType`, `tickerId`) — per ticker, so one shared post/article can be stored for BTC, ETH and SOL

3. **`sentiment_records`** — Granular sentiment outputs generated by the Llama 3.1 model
   - `id` (uuid, primary key, default random)
   - `postId` (uuid, foreign key referencing `raw_posts.id`, cascade delete, not null, unique)
   - `tickerId` (uuid, foreign key referencing `tickers.id`, cascade delete, not null)
   - `label` (sentiment_label enum, not null)
   - `score` (numeric(4,3), not null) — `-1.0` (bearish) to `+1.0` (bullish)
   - `confidence` (numeric(4,3)) — `0.0` to `1.0`
   - `reasoning` (text) — AI-provided rationale
   - `embedding` (vector(1536)) — Nvidia NIM generated Llama embedding vector
   - `analyzedAt` (timestamp, default now, not null)
   - *Indexes*: `sentiment_ticker_idx` (`tickerId`), `sentiment_analyzed_at_idx` (`analyzedAt`)

4. **`sentiment_timeseries`** — Rollups of sentiment scores by interval
   - `id` (uuid, primary key, default random)
   - `tickerId` (uuid, foreign key referencing `tickers.id`, cascade delete, not null)
   - `sourceType` (source_type enum, nullable) — Null indicates aggregate of all sources combined
   - `bucketStart` (timestamp, not null)
   - `interval` (interval_type enum, not null) — e.g. `1h`
   - `avgScore` (numeric(5,4))
   - `totalPosts` (integer, default 0, not null)
   - `bullishCount` (integer, default 0, not null)
   - `bearishCount` (integer, default 0, not null)
   - `neutralCount` (integer, default 0, not null)
   - `volumeWeightedScore` (numeric(5,4)) — Weighted score incorporating recency, credibility, and log-scaled upvote counts
   - `spotPrice` (numeric(20,8)) — Snap spot price of asset during interval bucket
   - *Indexes*: `ts_ticker_bucket_idx` (`tickerId`, `bucketStart`), unique index `ts_unique_bucket` (`tickerId`, `bucketStart`, `interval`, `sourceType`)

5. **`scrape_cache`** — Prevents redundant scraping and tracks errors
   - `id` (uuid, primary key, default random)
   - `tickerId` (uuid, foreign key referencing `tickers.id`, cascade delete, not null)
   - `sourceType` (source_type enum, not null)
   - `lastFetchedAt` (timestamp, default now, not null)
   - `postCount` (integer, default 0)
   - `status` (varchar(20), default "success") — `success` | `error` | `in_progress`
   - `errorMessage` (text)
   - *Indexes*: unique index `scrape_cache_unique` (`tickerId`, `sourceType`)

6. **`market_indicators`** — Stores numeric market indicators
   - `id` (uuid, primary key, default random)
   - `tickerId` (uuid, foreign key referencing `tickers.id`, cascade delete, nullable) — Null for global indicators like Fear & Greed
   - `indicatorType` (varchar(50), not null) — `fear_greed` | `funding_rate`
   - `value` (numeric(12,6), not null) — Raw numeric indicator reading
   - `label` (varchar(50), nullable) — Score classification (e.g. `extreme fear`, `bullish`)
   - `metadata` (jsonb) — Arbitrary metadata (e.g. `{ score, annualizedRate }`)
   - `collectedAt` (timestamp, not null)
   - `createdAt` (timestamp, default now, not null)
   - *Indexes*: `mi_ticker_type_idx` (`tickerId`, `indicatorType`), `mi_collected_at_idx` (`collectedAt`)

## Key Design Decisions

### Reddit Scraper Architecture (Arctic Shift Primary Pipeline)
Reddit's public JSON API (`reddit.com/r/x.json`) is 403-blocked on all server and datacenter IPs (Vercel, AWS, Neon) due to aggressive Cloudflare bot protection, and Reddit discontinued self-service OAuth app registration in 2025. 
To guarantee reliability and 100% data availability, [lib/scrapers/reddit.ts](file:///C:/Users/ajink/OneDrive/Desktop/personal%20-%20coding%20-%20ventures/crypto-mood/lib/scrapers/reddit.ts) bypasses `reddit.com` entirely and uses **Arctic Shift** (`arctic-shift.photon-reddit.com/api/posts/search`) as the primary data source. Arctic Shift is a public Reddit archive mirror with a 1–6 hour sync latency, which is ideal for our 35% multi-day community sentiment baseline.

Key defensive and processing strategies retained:
1. **Adaptive AbortController Timeout**: Requests are capped at 25 seconds to account for Arctic Shift search queries on large subreddits without hanging serverless runners.
2. **Cursor-Based Deep Pagination (`fetchArcticShiftPaginated`)**: Sorts strictly by `created_utc` (`desc`) and extracts the oldest post timestamp as `&before=${timestamp}` to traverse up to 10 pages per subreddit across a 14-day historical window.
3. **Sequential Jitter Delay**: Employs randomized 350ms–400ms jittered delays between page requests to avoid burst rate-limiting.
4. **Realistic User-Agent Pool Rotation**: Rotates modern desktop browser User-Agents (without "Bot" strings) to avoid CDN challenges.
5. **Multi-Subreddit & Coin Keyword Filtering**: Monitors 12+ subreddits (`r/bitcoin`, `r/ethereum`, `r/solana`, `r/CryptoCurrency`, `r/CryptoMarkets`). Dedicated subs are automatically mapped; broad crypto subs are filtered with strict ticker and ecosystem regex patterns (e.g. for SOL: `pump.fun`, `raydium`, `phantom wallet`, `$sol`).
6. **Defense F (Noise & Content Filter)**: Strips stickied moderator megathreads, mod/admin distinguished posts, deleted authors (`[deleted]`), removed bodies (`[removed]`), locked threads, and thin posts (< 20 chars).
7. **Deduplication & Storage**: Batch inserts in chunks of 50 into Neon PostgreSQL `raw_posts` with `(externalId, sourceType, tickerId)` unique constraint (`.onConflictDoNothing()`); inserted counts come from `.returning()`, so they are rows actually written.
8. **Defense G (Cache Flag Locking)**: Updates `scrape_cache` status to `in_progress` immediately upon initiation to prevent concurrent cron overlaps.

### News Scraper Content Extraction
Replaced the paid `ScrapeGraphAI` LLM-based scraping system with a free, custom-crafted Cheerio scraper in [lib/scrapers/news.ts](file:///C:/Users/ajink/OneDrive/Desktop/personal%20-%20coding%20-%20ventures/crypto-mood/lib/scrapers/news.ts).
- Removes noise tags (scripts, footers, advertisements, sidebars, nav bars).
- Probes a list of container selectors (`article`, `main`, `.post-content`, `.article-body`, etc.).
- Truncates extracted text body to 8,000 characters and filters out articles that don't pass ticker-matching validation (matching name, symbol, or CoinGecko ID).
- Extends individual article request timeouts to 15s to bypass lagging networks.

### CoinGecko News Scraper Integration
- Scrapes CoinGecko news updates via `/coins/{id}/news` (rather than synthetic post workarounds).
- Supports cache bypass with the `force` query option to verify latest data on-demand.
- Rotates demo API keys through standard HTTP headers (`x-cg-demo-api-key`).

### AI Sentiment Analysis Engine
- Employs Nvidia NIM hosting `nvidia/nemotron-3.5-lightning-30b-a3b` (constant `SENTIMENT_MODEL` in `lib/ai/sentiment.ts`) for JSON sentiment classification. Calls pass `providerOptions.nim.chat_template_kwargs.enable_thinking = false`; Nemotron 3.5 models are reasoning models and return null content with thinking on. History: Llama 3.1 8B → Llama 3.2 11B Vision (unresponsive Oct 2026) → Nemotron 3.5 Lightning (rate-limited after ~30 calls, NIM limits are per model) → Bolt (hung on every call 2026-10-30) → back to Lightning.
- **Score/label alignment:** the prompt gives bullish/bearish/neutral examples, and `alignScore()` forces the score's sign to match the label (neutral is clamped to ±0.2), because Bolt sometimes copied a positive example score onto bearish labels.
- **Throughput:** pending posts are analyzed newest first (the dashboard reads 48h/7d windows). Calls are paced client-side (`NIM_RPM`, default 240) and back off 15s on 429. Embeddings are fetched in one `getEmbeddings()` call per batch (default batch size 10) instead of one call per post.
- **Fail-fast:** if the first 6 posts in an `analyzePendingPosts` run all fail (or every post fails), it throws `AIModelDownError` instead of waiting out timeouts on every post. Unparseable model output is no longer stored as a fake neutral record; the post stays unanalyzed and is retried next run. `/api/analyze` catches the error so the dashboard still serves cached data.
- **Health check:** `checkAIHealth()` sends one known-bullish post through the chat and embedding models. `scripts/check-ai-health.ts` runs it as the first step of every GitHub Actions run. The chat call retries up to 2 times (25s timeout each), so one slow NIM response doesn't fail the run; a retired model still fails every attempt.
- Embeddings generated via Nvidia Nemotron-3 Embed 1B (`nvidia/nemotron-3-embed-1b`) and sliced to 1536 dimensions for Neon PostgreSQL `pgvector` indexing.
- Analyzes up to `limit` posts per call (50 default), 10 per batch.
- Custom fallback parser parses sentiment labels, scores, confidence readings, and reasonings from JSON output strings even if the model fails to return clean JSON blocks.

### Timeseries Pre-aggregations
- Pre-computes 1-hour intervals for timeseries charts.
- Weights scores using a **Recency Decay** algorithm (posts have a half-life of 12 hours) combined with **Source Credibility weights** (News = 1.0, CoinGecko = 0.9, Reddit = 0.7) and **Log-scaled Upvote Boosts** so viral community posts don't skew indicators.

### Retro CRT Terminal Loader
- A subtle, minimal CRT loading modal with a blurred backdrop (`backdrop-blur-md`) overlays the workspace during coin analysis, search, or sync updates.
- Features a clean 180px SVG dial scale showing ticks and labels (`-100` to `+100`) without any text overlap inside the dial.
- Splits the Gauge Panel into a 2-column card layout: the dial sits on the left, and the large spring-animated score (e.g. `+12`), state badges, and weighting info sit clearly on the right side.
- Enforces a 1200ms minimum display threshold to stay snappy and low-footprint while completing the scroll sequence.

### Editorial Dark Glass design system (site-wide)
Adapted from the taste reference `../adgrid-ui/adgrid-ui/desgin-bh.md` (the language, not the portfolio content). Every page uses it. **Display font is Jersey 10** (`--font-jersey` → `--font-display`, weight 400 only, no italic) for headlines, big numerals and the wordmark. **Accent words are static and extruded**, not animated: `.ed-accent` is an off-white face with four stepped grey `text-shadow` layers (~0.05em deep, scales with size) plus one soft contact shadow. The face is solid on purpose, because text-shadow paints over a `background-clip:text` fill. The old flowing gradient (`ed-gradient-x`) is gone. Charts follow void-ui: plots sit in `.ed-tray` (recessed well), series use luminance/dash tones, and bullish/bearish keep muted status colours `rgb(126 190 152)` / `rgb(229 115 115)` only where colour is the data. Tokens, `@property` and `@keyframes` sit top-level in `app/globals.css`; all `ed-*` class rules sit in `@layer components` so Tailwind utilities (`absolute`, `rounded-*`, `p-*`, colours) can override them. The site-wide `--font-sans` is Bricolage Grotesque and the page background is `#0d0d0f`.
- **Shared components restyled:** `BeveledCard` (raised = `ed-bento`), `DoubleBezel` (via BeveledCard), `GlowCard` (`ed-bento`; the `accent` prop is kept for API compatibility and ignored), `SectionEyebrow` (square + `ed-eyebrow`), `ObsidianDotGrid` surfaces and inputs (`ed-input`, `ed-chip`).

- **Other primitives:** `.ed-input` (hairline input well with a blue focus ring), `.ed-tag` (ring pill), `.ed-wordmark`.
- **Type:** Instrument Serif (`font-display`) for headings and big numbers, Bricolage Grotesque (`font-grotesk`) for UI, JetBrains Mono for data. Fonts are loaded in `app/layout.tsx` as `--font-instrument-serif` / `--font-bricolage`. Its `ed-chip` indicator springs (`layoutId="coinIndicator"`, stiffness 500 / damping 35 / mass .6) to the hovered coin at 0.85 opacity and back to the active coin on leave.
