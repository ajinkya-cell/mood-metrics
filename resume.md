## Projects

**MoodMetrics — Crypto Sentiment Engine** · [`live`] · [`github`]
Aggregates crypto sentiment from 5 sources (Reddit, CoinGecko, RSS news, Binance funding rates, Fear & Greed Index) into a single configurable score. Runs Llama 3.1 8B via Nvidia NIM for AI sentiment analysis with pgvector embeddings for semantic search over historical verdicts. Built a Reddit scraper with 8 anti-blocking defenses; replaced a paid ScrapeGraphAI pipeline with a Cheerio-based alternative. Strategy backtester with Monte Carlo fallback. 5 analytical tools: lag correlation, narrative projection, trajectory clustering, whale vs retail, historical playback.

**DevDiscuss** · [`github`] · [`live`]
Full-stack developer Q&A platform. PostgreSQL full-text search with GIN indexing. Trending ranking algorithm weighting votes and accepted solutions. Modular backend via Next.js API routes and Drizzle ORM — user profiles, follow systems, paginated problem browsing.

**Doodleboard** · [`github`] · [`live`]
Real-time collaborative whiteboard built from scratch using the native Canvas API — zero external drawing libraries. Custom rendering engine for shapes, freehand, text (coordinate math, path rendering, hit detection). WebSocket sync for simultaneous multi-user drawing.

**Redis Chat** · [`github`] · [`live`]
Anonymous self-destructing chat — rooms and messages expire after 10 minutes via Redis TTL. In-memory datastore for ephemeral state. Full-stack Next.js + TypeScript.
